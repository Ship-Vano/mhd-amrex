# Отчёт: 2D-решатель идеальной МГД с гарантией ∇·B = 0 на AMReX

**Схема:** Авдеева–Лукин (2019), декартова staggered-реализация · **Поток:** HLLD ·
**Интегратор:** SSP-RK2, CFL = 0.5 · **AMR:** amrex::AmrCore ·
**Конфигурация:** JSON · **Вывод:** plotfile/HDF5 → ParaView

---

## 1. Постановка и схема

Решается система идеальной МГД (обозначения статьи Авдеевой–Лукина, ур. (1)–(4);
энергия и давление включают магнитную часть, множители 4π убраны нормировкой
B → B/√4π):

- ∂ρ/∂t + ∇·(ρ**v**) = 0
- ∂(ρ**v**)/∂t + ∇·(ρ**vv** + p_T Î − **BB**) = 0
- ∂e/∂t + ∇·[(e + p_T)**v** − **B**(**v**·**B**)] = 0
- ∂**B**/∂t = ∇×(**v**×**B**),  ∇·**B** = 0

### 1.1. Расположение переменных (staggered)

Статья формулирует метод на неструктурированных треугольных сетках: газовые
величины — в ячейках, нормальные компоненты **B** — на рёбрах, ЭДС усредняется
в вершины из HLLD-потоков, закон Фарадея аппроксимируется напрямую по теореме
Стокса, поле внутри ячейки восстанавливается базисом Равьяра–Тома. На
блочно-структурированной сетке AMReX тот же метод принимает классическую
CT-форму (прообраз — Balsara & Spicer 1999, на которую ссылается и статья):

| Величина | Расположение |
|---|---|
| ρ, ρu, ρv, ρw, e, Bz | центры ячеек (MultiFab `state_`) |
| Bx | x-грани (i±½, j) |
| By | y-грани (i, j±½) |
| Ez | узлы (i±½, j±½) |

Клеточные копии Bx, By (для решателя Римана и вывода) получаются
RT0-интерполяцией: на прямоугольной ячейке базис Равьяра–Тома даёт линейное по
нормали поле, и среднее по ячейке равно полусумме противоположных граней.

### 1.2. Шаг схемы

1. **MUSCL-реконструкция** примитивных переменных к граням (лимитеры MC /
   minmod / van Leer; `"limiter":"none"` возвращает 1-й порядок исходной
   статьи). Нормальная компонента поля на грани **не реконструируется** — она
   берётся из staggered-массива и непрерывна через грань (ключевое свойство).
2. **HLLD** (Miyoshi & Kusano 2005, 6 состояний / 5 волн) на каждой грани даёт
   поток газовых величин и компоненту потока тангенциального поля:
   на x-грани F[By] = uBy − vBx = −Ez, на y-грани G[Bx] = vBx − uBy = +Ez.
3. **Узловая ЭДС** — среднее ЭДС четырёх примыкающих граней (точный декартов
   аналог усреднения по рёбрам при вершине, формула (8) статьи). Доступны два
   варианта (`"emf_averaging"`):
   * `balsara_spicer` — простое арифметическое среднее, как в статье;
   * `gardiner_stone` (по умолчанию) — Ez = 2⟨Ez⟩грани − ⟨Ez⟩ячейки
     (Gardiner & Stone 2005): восстанавливает порядок аппроксимации и даёт
     запас устойчивости при CFL ≈ 0.5.
4. **Газовые величины** — годуновский баланс потоков по ячейке.
5. **Закон Фарадея по Стоксу** для граней:
   Bxⁿ⁺¹ = Bx − (Δt/Δy)(Ez↑ − Ez↓), Byⁿ⁺¹ = By + (Δt/Δx)(Ez→ − Ez←).
   Дискретная дивергенция (ΔBx/Δx + ΔBy/Δy) телескопически сокращается —
   **div B сохраняется точно**, никакие чистки (Пауэлл, проекция, GLM) не нужны.

### 1.3. Выбор интегратора по времени

Рассматривались три варианта.

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **Расщепление Стрэнга** (x/y-прогонки) | простота, большой CFL по направлению | расщепление ломает согласование ЭДС в узлах: между прогонками граневое B одного направления «старше» другого, точное сохранение div B требует спец. конструкции; ошибка расщепления O(Δt²) с большой константой на сильных вихрях | отклонён |
| **CTU + CT** (corner transport upwind, Colella; Gardiner & Stone 2005) | неразрезной, CFL до 1, наилучшая точность | требует характеристического трассирования МГД (собств. векторы 7-волновой системы) и поперечных поправок к ЭДС — самый сложный в реализации и сопровождении | избыточен для целей проекта |
| **SSP-RK2 (Хойна)** | неразрезной; 2-й порядок; каждая стадия — полноценное CT-обновление, выпуклая комбинация бездивергентных полей бездивергентна ⇒ div B = 0 сохраняется автоматически; тривиально совместим с AMR-синхронизацией | устойчив до CFL ≈ 0.5 (а не 1.0) | **выбран** |

Реализованы `rk2` (по умолчанию) и `euler` (1-й порядок, режим исходной
статьи). CFL = 0.5 задан в примерах; верификационные расчёты ниже выполнены
при CFL = 0.4 (с запасом).

### 1.4. AMR (AMReX)

Дизайн опирается на туториал `Amr/Advection_AmrCore` и приёмы МГД-кодов на
AMReX (Quokka, AMReX-Astro): класс `MhdAmr : amrex::AmrCore` реализует
`MakeNewLevelFromScratch/FromCoarse`, `RemakeLevel`, `ClearLevel`, `ErrorEst`.

* **Критерии измельчения:** относительный градиент плотности
  (|Δρ|/ρ > `refine_grad_rho`) и/или ток jz = (∇×B)z (`refine_current`).
* **Интерполяция на мелкий уровень:** клеточные величины —
  `cell_cons_interp`; граневые B — **`amrex::face_divfree_interp`**
  (бездивергентный интерполянт AMReX: дивергенция мелких ячеек наследует
  нулевую дивергенцию грубой).
* **Согласование уровней:** расчёт ведётся **без подциклирования** (общий Δt,
  определяемый самым мелким уровнем). Перед применением закона Фарадея узловые
  ЭДС мелкого уровня инжектируются в совпадающие узлы грубого
  (`average_down_nodal` + `ParallelCopy`). Тогда обновление грубой грани на
  границе уровней
  (Ez(верх) − Ez(низ))/Δy_c **в точности** равно среднему обновлений двух
  накрывающих её мелких граней: ½[(Ez(верх)−Ez(сер)) + (Ez(сер)−Ez(низ))]/Δy_f.
  Поэтому последующие `average_down`/`average_down_faces` не вносят
  дивергенцию, и div B = 0 на всей иерархии. Это та же идея, что EMF-рефлюкс
  Balsara (2001), но без временно́го усреднения благодаря общему Δt.

### 1.5. Граничные условия

Реализованы все типы, требуемые тестами статьи и ВКРБ (задаются в JSON
по-сторонне): `periodic` (Орзаг–Танг, альфвеновская волна), `outflow`
(свободный вынос — ротор, петля), `reflect` (зеркало: нечётные нормальные
v и B), `dirichlet` — «исторические» ГУ из ВКРБ (значения НУ заморожены на
границе; Брио–Ву). Для клеточных величин ГУ идут через BCRec/FillPatch AMReX,
для граневых B — специализированным наполнителем фантомных граней.

### 1.6. Параллелизация и производительность

* **MPI** — доменная декомпозиция AMReX (BoxArray/DistributionMapping),
  обмены — `FillBoundary`/`FillPatch`; редукции Δt и div B —
  `ParallelDescriptor::Reduce*`.
* **OpenMP** — тайлинг `MFIter(..., TilingIfNotGPU())` внутри ранга.
* Ядра (`src/kernels`) написаны без зависимостей от AMReX и снабжены
  макросом `MHD_HD` → `AMREX_GPU_HOST_DEVICE`, т.е. готовы к переносу циклов
  на `amrex::ParallelFor` для GPU.
* Использованы готовые средства AMReX: FillPatch-утилиты, бездивергентные
  интерполяторы, `average_down(_faces/_nodal)`, plotfile/HDF5-вывод,
  тегирование и построение сеток.

### 1.7. Вывод результатов

`"format": "hdf5"` → `WriteMultiLevelPlotfileHDF5` (требует сборки с
`-DMHD_HDF5=ON`; один `.h5` на снимок, коллективный MPI-IO — быстрее тысяч
мелких файлов на параллельных ФС). `"format": "native"` → стандартный
plotfile. **Оба формата ParaView (≥5.7) читает напрямую** (AMReX/BoxLib Grid
Reader и HDF5-reader соответственно), включая AMR-иерархию. Поля вывода:
ρ, u, v, w, p, Bx, By, Bz и диагностическая `divB`.

## 2. Верификация

Вычислительные ядра проекта (HLLD, MUSCL, CT) собраны автономным драйвером
`tests/standalone_verify.cpp` (однородная сетка, те же заголовки из
`src/kernels`) и прогнаны на классических тестах. Параметры: MUSCL-MC, RK2,
CFL = 0.4, усреднение ЭДС Gardiner–Stone. Графики — `scripts/plot_verification.py`.

### 2.1. Брио–Ву (ударная труба)

**Начальные условия** (γ = 2, Bx = 0.75, область [0,1]×[0,0.01], t_end = 0.1):

| | ρ | p | u,v,w | By | Bz |
|---|---|---|---|---|---|
| x < 0.5 | 1 | 1 | 0 | 1 | 0 |
| x > 0.5 | 0.125 | 0.1 | 0 | −1 | 0 |

ГУ — `dirichlet` («исторические», как в ВКРБ). Сетка 512×4.

**Результат** (`briowu.png`): воспроизведена эталонная пятиволновая структура —
быстрая волна разрежения, **составная волна** (медленный скачок + примыкающее
разрежение, пик плотности у x ≈ 0.47), контактный разрыв, медленный скачок,
быстрое разрежение справа; фронты разрешаются в 2–3 ячейки, что согласуется со
статьёй («2 слоя ячеек на фронте»). Небольшие посткочковые осцилляции u и By
(амплитуда ~2%) типичны для MC-лимитера и убираются `"limiter":"minmod"`.

**Метрики:** max|divB| за весь расчёт = **0.0** (тождественно: начальное поле
кусочно-постоянно, ЭДС-разности сокращаются точно). Сходимость к эталонному
профилю — 1-й порядок по L1 (разрывное решение), как и в ВКРБ (табл. 2 ВКРБ).

### 2.2. Циркулярно поляризованная альфвеновская волна (гладкий тест)

**Постановка** (ВКРБ §4.1.1, Tóth 2000): угол распространения **α = 30°** к оси
Ox, область Ω = [0, 1/cos α]×[0, 1/sin α], периодические ГУ, γ = 5/3,

ρ = 1, p = 0.1, v∥ = 0, B∥ = 1, v⊥ = B⊥ = 0.1 sin φ, vz = Bz = 0.1 cos φ,
φ = 2π(x cos α + y sin α).

Волна бежит со скоростью c_A = B∥/√ρ = 1; при t = 1 решение совпадает с НУ —
ошибка измеряется против аналитики. Поле задаётся векторным потенциалом
Az = y cos α − x sin α + (0.1/2π)cos φ разностным ротором ⇒ начальная div B
машинно нулевая.

**Сходимость** (L1/L2 по B⊥ против точного решения, t = 1):

| N (ячеек по Ox) | L1(B⊥) | L2(B⊥) | порядок (L1) | max divB за расчёт |
|---|---|---|---|---|
| 16 | 6.542·10⁻³ | 7.379·10⁻³ | — | 1.3·10⁻¹³ |
| 32 | 1.923·10⁻³ | 2.124·10⁻³ | **1.77** | 2.2·10⁻¹³ |
| 64 | 5.534·10⁻⁴ | 6.136·10⁻⁴ | **1.80** | 1.4·10⁻¹² |

Порядок стремится ко 2-му (MUSCL+RK2) — против ~1.2–1.3 у схемы 1-го порядка в
ВКРБ (табл. 3 ВКРБ), т.е. реконструкция даёт ожидаемое улучшение. Профили
B⊥(ξ) на разных сетках — `alfven_profiles.png` (фазовая ошибка убывает,
N = 64 визуально совпадает с аналитикой).

### 2.3. Вихрь Орзага–Танга

**Начальные условия** (периодический квадрат [0,1]², γ = 5/3, t_end = 0.5):

ρ = 25/36π, p = 5/12π (скорость звука = 1), u = −sin 2πy, v = sin 2πx,
Bx = −B₀ sin 2πy, By = B₀ sin 4πx, **B₀ = 1/√4π** (нормировка кода без 4π;
в записи ВКРБ/статьи с √4π-единицами поля это эквивалентно Bx = −sin 2πy).
Поле задано потенциалом Az = B₀(cos 4πx/4π + cos 2πy/2π).

**Целевые показатели:** к t = 0.5 гладкое течение порождает систему
взаимодействующих ударных волн и центральный токовый слой; эталон — карты ρ, p
(Athena/Tóth) и профиль давления вдоль y = 0.3125 (рис. 8 статьи
Авдеевой–Лукина).

**Результат** (сетка 192², 611 шагов): карты `ot_maps.png` воспроизводят
каноническую морфологию; профиль `ot_pressure_slice.png` повторяет рис. 8
статьи — скачок при x ≈ 0.28 (p ↓ до ~0.06), плато p ≈ 0.10, максимум
p ≈ 0.26 при x ≈ 0.58, резкий сброс при x ≈ 0.70, ширина фронтов 2–3 ячейки
без паразитных осцилляций.

**Метрики:** max|divB| за весь расчёт = **1.2·10⁻¹²** (накопление ошибок
округления за ~600 шагов; рост линейный по числу шагов, физического роста нет).

### 2.4. Вращающийся цилиндр (rotor)

Постановка ВКРБ §4.1.2/Tóth: [0,1]², γ = 1.4, Bx = 5/√4π, диск ρ = 10,
r₀ = 0.1, v₀ = 2 со сглаживающим кольцом до r₁ = 0.115, ГУ — outflow,
t_end = 0.15. Результат (`rotor_maps.png`): альфвеновские «крылья» вытягивают
вихрь, центральная область сохраняет гладкое вращение; max|divB| = 1.1·10⁻¹²,
неустойчивостей нет — тест на устойчивость пройден.

## 3. Пример кода: ядро бездивергентного обновления

```cpp
// узловая ЭДС = среднее ЭДС четырёх примыкающих граней (ф.(8) статьи);
// ЭДС берётся из HLLD-потока: на x-грани Ez = -F[By], на y-грани Ez = +G[Bx]
ez(i,j) = corner_emf(-fx(i,j-1,UBY), -fx(i,j,UBY),
                      fy(i-1,j,UBX),  fy(i,j,UBX), ..., emf_mode);

// закон Фарадея по теореме Стокса — дивергенция сокращается телескопически
bx(i,j) -= dt/dy * (ez(i,j+1) - ez(i,j));
by(i,j) += dt/dx * (ez(i+1,j) - ez(i,j));
```

## 4. Известные ограничения и развитие

* Полная энергия обновляется потоками HLLD; после CT-коррекции граней
  клеточное B меняется на O(h²) — стандартная для CT-кодов несогласованность
  энергии (как в Athena); при желании включается пересчёт внутренней энергии.
* AMR без подциклирования прост и точен, но на глубоких иерархиях дороже
  подциклирования; переход на subcycling потребует EMF-рефлюкса с временны́м
  усреднением (Balsara 2001).
* AMReX-слой зафиксирован на теге 25.01; сигнатуры FillPatch для граневых
  массивов в других версиях могут отличаться.
* GPU: ядра готовы (`MHD_HD`), циклы `LoopOnCpu` переводятся на
  `amrex::ParallelFor` механической заменой.
